# The file is the text

From Phase 7 the code panel's text, not the model, is what a document holds whenever the two differ. While any line is invalid, text edits don't reach the canvas, which keeps its last valid model (on load, the model built from the lines that parse); Save and recovery files write the panel text as shown, never the model; and every undo step records the panel text whenever it isn't plain regenerated text, so a canvas edit that regenerates away invalid lines, or an Undo pressed while the text is invalid, can always be taken back with the typing intact. We chose this so nothing the writer types is ever lost to a parse error, and so a half-typed line never makes shapes flicker off the canvas, which applying valid lines one by one would do. The cost: a single invalid line freezes every other text edit until it is fixed, a saved file is not always canonical, and the history carries text alongside the model.
